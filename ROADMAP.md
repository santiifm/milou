# Milou Roadmap

## ✅ Completed Milestones
- [x] **Phase 1**: Clean Architecture & Domain Separation
- [x] **Phase 2**: Event-Driven Communication (EventBus)
- [x] **Phase 3**: Persistent Background Job Manager
- [x] **Phase 4**: Data-Driven Emulator Launcher
- [x] **Phase 5**: Metadata Scraper Engine & Offline Assets

## 🚀 Future Features
- [ ] **Library Scanner**: Automatic import of existing local ROM collections.
- [ ] **Duplicate Detection**: Identify and group duplicate ROMs across consoles.
- [ ] **Favorites & Play History**: Tracking your gaming habits and shortcuts.
- [ ] **Playtime Statistics**: Measure how much time you spend in each game.
- [ ] **Controller-First Navigation**: Full support for gamepads in the UI.
- [ ] **Themes & Customization**: Dynamic library layouts and color schemes.
- [ ] **Cloud Backup**: Sync your metadata and settings across devices.
- [ ] **Full-Screen "Appliance Mode"**: A simplified UI for handheld devices.
